# 用户故事生成技能

## 描述
根据用户提供的功能描述，自动生成完整的用户故事清单，每个故事包含用户故事、验收标准、优先级和依赖关系，可直接用于敏捷开发排期。

## 使用场景
- 用户要求生成用户故事
- 用户需要将功能需求拆解为开发可执行的故事
- 用户提到"用户故事""Story""验收标准""AC""Story Map"等关键词
- Sprint 规划前需要梳理 Backlog

## 指令

### 第一步：需求理解
1. 仔细阅读用户提供的功能描述
2. 识别功能涉及的角色（用户类型）
3. 识别功能涉及的核心场景
4. 如功能描述太模糊，向用户追问（最多 2 个问题）

### 第二步：用户故事生成规则

#### 故事格式
```
作为【角色】，
我希望【功能/操作】，
以便【价值/目的】。
```

#### 验收标准格式
```
验收标准 1：在【前置条件】下，当【操作】时，预期【结果】
验收标准 2：在【异常条件】下，当【操作】时，预期【结果】
```

#### 优先级定义
- P0：核心流程，没有这个功能无法使用
- P1：重要功能，影响体验但不阻断核心流程
- P2：锦上添花，可后续迭代

### 第三步：输出结构

#### 1. 角色梳理
| 角色 | 说明 |
|------|------|
| 普通用户 | 产品的日常使用者 |
| 管理员 | 拥有管理权限的用户 |
| 访客 | 未登录用户 |

#### 2. 用户故事清单

按优先级排序，每个故事包含：

```
## Story-001：[故事标题]
**优先级：** P0
**角色：** 普通用户
**故事：** 作为普通用户，我希望xxx，以便xxx。

**验收标准：**
1. 在已登录状态下，点击xxx按钮，预期跳转到xxx页面
2. 在未登录状态下，点击xxx按钮，预期弹出登录引导
3. 在网络断开状态下，点击xxx按钮，预期显示"网络异常"提示

**依赖：** 无 / 依赖 Story-001
**估算：** S/M/L
```

#### 3. Story Map（文字版）
```
                  P0（MVP）        P1（重要）        P2（后续）
注册登录    | Story-001       | Story-005       | Story-008
核心功能    | Story-002       | Story-006       |
辅助功能    | Story-003       | Story-007       | Story-009
```

#### 4. 依赖关系图
```
Story-001（注册登录）→ Story-002（核心功能A）→ Story-004（核心功能B）
                                          → Story-006（优化体验）
```

### 第四步：生成要求
- 每个功能至少生成 3 个用户故事
- 每个故事至少 2 条验收标准（1 条正常 + 1 条异常）
- 覆盖所有角色
- 覆盖正常流程、边界条件和异常场景
- P0 故事必须可以独立交付（或只依赖已完成的 Story）

### 第五步：质量检查
- [ ] 是否覆盖了所有角色
- [ ] 每个故事的验收标准是否可测试
- [ ] 异常场景是否覆盖（网络断开、空数据、权限不足等）
- [ ] 依赖关系是否合理（无循环依赖）
- [ ] P0 故事是否可以组成最小可用产品（MVP）

## 示例

**用户输入：** 我们要做一个商品搜索功能

**输出（节选）：**

### 角色梳理
| 角色 | 说明 |
|------|------|
| 普通用户 | 已登录的购物用户 |
| 访客 | 未登录的浏览用户 |

### Story-001：关键词搜索商品
**优先级：** P0
**角色：** 普通用户/访客
**故事：** 作为用户，我希望通过输入关键词搜索商品，以便快速找到我想要的商品。

**验收标准：**
1. 在搜索框输入关键词并点击搜索，预期 1 秒内返回匹配的商品列表
2. 搜索框为空时点击搜索，预期显示搜索建议/热门搜索
3. 搜索结果为空时，预期显示"未找到相关商品"并推荐热门商品
4. 搜索关键词超过 50 字符时，预期截取前 50 字符进行搜索

**依赖：** 无
**估算：** M

### Story-002：搜索结果筛选
**优先级：** P1
**角色：** 普通用户/访客
**故事：** 作为用户，我希望对搜索结果按价格、销量筛选排序，以便更快找到合适的商品。

**验收标准：**
1. 点击"价格从低到高"，预期商品列表按价格升序排列
2. 同时选择"100-500元"价格区间和"销量优先"，预期结果同时满足两个条件
3. 筛选后无结果时，预期提示"当前筛选条件下无商品"并建议调整筛选

**依赖：** Story-001
**估算：** M
